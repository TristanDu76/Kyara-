# Confidentialité — Kyara Plus

Kyara Plus ne contient ni télémétrie, ni publicité, ni service de collecte externe. Aucun événement d’usage, historique de cartes ou identifiant de compte n’est envoyé à l’auteur de l’extension.

L’extension lit les données de Kyara et utilise les actions du site pour fournir les fonctions demandées : collection, wishlist, échanges, verrouillage et ouverture de boosters. Ces échanges se font avec Kyara dans la session de l’utilisateur. L’extension ne demande aucune permission d’accès aux cookies.

Les réglages, modèles de requêtes et historiques sont conservés localement dans le stockage du site de ce navigateur. Les échéances de réveil sont conservées dans le stockage de session de l’extension. Aucun de ces éléments n’est synchronisé par le dépôt GitHub.

La signature privée d’une version Firefox nécessite de soumettre le paquet de code à Mozilla. Les données de votre compte Kyara et votre historique local ne font pas partie de ce paquet.
